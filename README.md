# Домашнее задание №4

**Название:** Калибровка станка (вариант 14)

**Автор:** Лошко Игорь Сергеевич, бТИИ-261

**Описание:** Программа запрашивает значения трёх параметров станка `A`, `B`, `C` и проверяет условие успешной калибровки: каждое из значений кратно трём. Результат выводится как 1 (условие выполнено) или 0 (не выполнено). Блок-схема алгоритма - в файле `blok_shema.png`.

**Компиляция:** Проект создан в Visual Studio 2022. Для сборки нажмите Build Solution.
